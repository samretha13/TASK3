# Coffee Rating Application ☕

A simple full-stack application where users can vote for their favorite coffee items. Each vote updates the count in the database using backend API logic.

---

## Features

- Display coffee list
- Vote button for each item
- Dynamic vote count updates
- Backend API integration
- MongoDB database support

---

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB
